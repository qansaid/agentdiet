# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Release notes and downloadable binaries for every version are also published on
the [GitHub Releases page](https://github.com/qansaid/agentdiet/releases).
Entries below are taken from those published release notes.

## [0.1.8] - 2026-11-07

### Added
- Detect Nakama profile workspaces during a scan.

### Fixed
- Override the vulnerable `minimatch` transitive dependency under
  `typescript-eslint` on the website.

## [0.1.7] - 2026-11-07

### Added
- Publish the AgentDiet product website.

### Changed
- Add a theme-aware banner, a pipeline diagram and a collapsible reference
  section to the README.
- Replace prose em dashes with ordinary punctuation in site copy.

### Other
- Script and document the Cloudflare Tunnel deployment.
